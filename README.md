# Superstore Sales Analysis Dashboard | Power BI

## 📊 Project Overview

This project is an interactive **Superstore Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard analyzes sales and business performance across different categories, sub-categories, regions, states, customer segments, shipping modes, payment modes, and time periods.

The main objective of this project is to convert raw sales data into meaningful visual insights that can help understand **sales performance, profitability, customer segments, shipping patterns, and regional performance**.
